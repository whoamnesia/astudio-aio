# Token architecture and format

## 1. Three layers
```
Primitive   raw values            --primary-600: #C2410C;  --space-4: 1rem;  --radius-8: 8px
   ↓
Semantic    purpose aliases       --color-primary: var(--primary-600);  --space-section: var(--space-24)
   ↓
Component   per-component knobs   --button-bg: var(--color-primary);  --card-padding: var(--space-6)
```
| Layer | Changes when | Who reads it |
|---|---|---|
| Primitive | rarely (brand refresh) | the semantic layer only |
| Semantic | theme switch (light/dark/brand variant) | all components |
| Component | one component needs independent theming | that component |

## 2. Naming
`--{category}-{item}-{variant}-{state}`: `--color-primary`, `--color-primary-hover`, `--button-bg-hover`,
`--space-section-sm`. Categories: color, font, text (size), leading, tracking, space, radius, shadow, border, duration,
ease, z, size (icons, controls), opacity, breakpoint.
Semantic colour roles used across astudio (generated by palette.py): ground, surface, raised, ink, muted, border,
control-border, primary, primary-hover, primary-text, on-primary, primary-subtle, accent, on-accent, success/warning/
danger/info + `-subtle` + `on-*-subtle`, focus, selection. Map to shadcn names when needed:
background=ground, foreground=ink, card=raised, muted=surface, muted-foreground=muted, border=border,
input=control-border, ring=focus, primary=primary, primary-foreground=on-primary, destructive=danger.

## 3. Scales
- **Spacing** (4px base): 0, 1(4), 2(8), 3(12), 4(16), 6(24), 8(32), 12(48), 16(64), 24(96), 32(128), 40(160).
  Semantic: component padding sm/md/lg, stack gaps, section gap (Persuade 120-240px desktop, 72-112 phone).
- **Type**: fluid modular scale from tokens.py (xs…5xl, display) - `clamp(min rem, rem + vw, max rem)`.
  Operate UI: fixed 12/14/16/18/24/32 is often clearer.
- **Radius**: none, sm 4, md 8, lg 16, xl 24, full 9999 - choose the logic from the brand's shape language.
- **Shadow**: sm (hover lift of floating items), md (popover/menu), lg (dialog); offset + soft blur, brand-tinted.
- **Motion**: durations press 140 / hover 180 / ui 240 / modal 320 / reveal 800 / open 1200 ms; easings out, expo,
  in-out, drawer, exit (`<root>/reference/motion.md`).
- **z-index**: base 0, dropdown 10, sticky 20, overlay 30, modal 40, toast 50.
- **Breakpoints**: 480, 768, 1024, 1280, 1440 (content-driven; container queries for components).

## 4. Dark mode
Override **semantic** tokens only:
```css
:root { --color-ground: #FFF9F7; --color-ink: #221814; }
@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { --color-ground: #110C0A; --color-ink: #F0EAE8; } }
:root[data-theme="dark"] { --color-ground: #110C0A; --color-ink: #F0EAE8; }
```
`color-scheme` on the root; a theme toggle sets `data-theme` and persists the choice; avoid a flash by setting the
attribute in an inline script in `<head>`.

## 5. W3C DTCG 2025.10 essentials (what tokens.py emits)
- File extension `.tokens.json`; media type `application/design-tokens+json`.
- A token is an object with `$value`; `$type` may be set on the token or inherited from a parent group; `$description`,
  `$extensions`, `$deprecated` are optional.
- Colour value is an object: `{"colorSpace": "srgb", "components": [r, g, b], "alpha": 1, "hex": "#rrggbb"}` (other
  spaces: oklch, display-p3, …).
- Dimension: `{"value": 16, "unit": "px"|"rem"}`. Duration: `{"value": 200, "unit": "ms"|"s"}`. cubicBezier:
  `[x1, y1, x2, y2]`. fontFamily: string or array. fontWeight: number 1-1000 or keyword. number.
- Composites: `typography {fontFamily, fontSize, fontWeight, letterSpacing, lineHeight}`, `shadow {color, offsetX,
  offsetY, blur, spread, inset?}` (or an array), `border`, `transition {duration, delay, timingFunction}`,
  `gradient`, `strokeStyle`.
- References: `"{group.token}"` (curly braces) - chained references allowed, circular ones forbidden; JSON Pointer
  (`#/color/primary`) must also be supported by tools. `$root` names a group's own token; `$extends` inherits a group.
- Tools that read it: Style Dictionary, Tokens Studio (Figma), Terrazzo, Figma variables import via plugins.

## 6. Validation
- `grep -rnE "#[0-9a-fA-F]{3,8}\b" src/ --include=*.{css,tsx,jsx,vue,svelte}` outside the token files → raw values to
  replace. Also hard-coded `px` font sizes, `box-shadow` literals, `transition` durations.
- Every text role pair re-checked with `palette.py contrast` after any change.
