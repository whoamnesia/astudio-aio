# Logo concepts: types, methods, word map

## 1. Mark types and the decision guide
| Type | What | Best for | Watch out |
|---|---|---|---|
| **Wordmark** | the name in custom/modified letters | short, distinctive, new names (≤ ~8 letters) | needs one ownable letter detail, not a stock font |
| **Lettermark / monogram** | initials as one form | long or multi-word names, professional firms, app icons | generic initials in a stock font = no mark |
| **Letterform symbol** | one initial with a twist (cut, fold, negative space) | compact symbol + wordmark lockups | must still read as the letter |
| **Pictorial** | a recognisable object | names/stories with a vivid ownable image | literalism; needs reduction |
| **Abstract** | non-representational shape expressing an idea | tech, differentiation, high exposure | needs exposure to earn meaning |
| **Combination** | symbol + wordmark lockup | most new brands - most versatile | define horizontal/stacked/symbol-only from the start |
| **Emblem / badge / seal** | symbol enclosed in a shape | heritage, craft, institutions, food & drink | scalability - design a simplified inner symbol |
| **Mascot** | a character | family, food, sport, games, kids | provide a simplified head version |

Decision guide - first strong yes wins:
1. Name short, distinctive, not yet known → wordmark or wordmark-led combination.
2. Name long, multi-word, hard to pronounce → lettermark/monogram or letterform + wordmark.
3. Name/story contains a vivid ownable image → pictorial (combination).
4. Strong idea but no object → abstract (only with high exposure).
5. Will live mostly as app icon/favicon/avatar → letterform or compact symbol first, lockup second.
6. Heritage, membership, authority, craft → emblem with a simplified inner symbol.
7. Warmth, family, play → mascot or friendly pictorial with a simplified head.
8. Parent brand with many children → a system with a fixed core.
When in doubt, the first round explores three different types (e.g. wordmark, letterform, abstract).

Database help: `search.py "<style words>" -d logo-style`, `search.py "<industry>" -d logo-industry` (recommended styles,
common symbols to avoid or transform, mood), `search.py "<mood>" -d logo-color`.

## 2. Concept methods (use one, combine two at most)
1. **Monogram + meaning** - the initial fused with a metaphor via a cut, fold or negative space (K + kite/frame;
   S + sound wave; A + ascent/architecture). Not a boring letter icon.
2. **Product action** - the main verb as an abstract form: build → frame/scaffold/block; protect → boundary/protected
   core; convert → switch/transformation; speak → wave/pulse; automate → loop/handoff/path; deliver → route/arrow.
3. **Metaphor fusion** - two meaningful ideas reduced into one mark (owl + drone vision; moon + waveform; shield +
   mountain; dice + mobile economy). Subtle and readable, not a puzzle.
4. **Negative space** - the hidden arrow, protected centre, cut-out initial, internal path, folded corner, an eye formed
   by crossing shapes. Design the negative shape first, then build the positive around it.
5. **Construction geometry** - a mark from a visible system: circles, diagonal cuts at clean angles, grids, modules,
   layered cards, orbits. One construction panel can explain it.
6. **Place / artefact** - from the subject inventory: the street's door number, the shop-front lettering, the
   stamp on the product, the shape of the building, a local material pattern.
7. **Name play** - the letters themselves hold the idea (a doubled letter as a pair of something, a letter rotated into
   a symbol, a ligature that only this name has).

## 3. Word map
Four columns: **name** (meaning, sound, letters, etymology) · **offering** (what they do, the product's action and
output) · **adjectives** (3-5 brand traits) · **promise** (the change for the customer). Under each write nouns,
metaphors, related objects, places, opposites. Circle intersections between columns - concepts live where two columns
meet (e.g. name "Pace" × offering "running club" × adjective "steady" → a metronome-like P built from three equal arcs).

## 4. Turning adjectives into form
| Adjective | Form cues |
|---|---|
| trustworthy, stable | symmetry, solid base, heavier weight, closed shapes, horizontal emphasis |
| dynamic, fast | diagonals (15-30°), forward lean, open shapes, motion cuts |
| friendly, warm | rounded terminals, circles, soft corners, humanist/round letterforms |
| precise, technical | sharp corners, exact angles, grid modules, monoline, geometric letterforms |
| premium, refined | restraint, thin-thick contrast, generous negative space, serif or high-contrast letterforms |
| playful | asymmetry, bounce in baseline, unexpected rotation, a character |
| natural, organic | irregular but controlled curves, leaf/water logic, imperfection with intent |
| bold, loud | heavy weight, compact counters, big shapes, high contrast |

## 5. Common category clichés (transform or avoid)
Tech/SaaS: abstract swooshes, infinity loops, hexagon networks, rockets, lightning bolts, "connected dots". Finance:
upward arrows, shields, columns, globes, coins. Health: crosses, hearts, leaves, hands. Dental: teeth, smiles. Real
estate: roofs, houses, keys. Coffee: beans, steam, cups. Food: chef hats, forks, flames. Legal: scales, columns,
gavels. Education: books, caps, owls. Eco: leaves, globes, recycling arrows. Fitness: flexing figures, dumbbells.
Crypto: coins, block cubes, "chain" links. Travel: planes, globes, map pins. Beauty: lips, faces in profile, lotus.

## 6. Cyrillic and bilingual names
If the brand lives in Russian and Latin, decide the primary script with the user. Design both wordmarks as a pair
(same stem width, x-height relationship, stroke contrast and terminal logic); Cyrillic letters (Ж, Ф, Щ, Ы, Л, Д) need
their own construction - do not fake them from Latin parts. A symbol that works without language helps bilingual brands.
