# Logo testing checklist

A logo is finished only when it has survived these. `logo_kit.py audit` covers structure; `logo_kit.py sheet` +
`render.cjs` give the visual tests; the rest is judgement. Run on every concept before presenting and again on finals.

## 1. Scale
- [ ] 16px favicon: the core idea survives (else design a small-size cut: fewer elements, thicker strokes, bigger gaps).
- [ ] 24-32px (app lists, avatars): recognisable at a glance.
- [ ] Very large (billboard): curves smooth, no lumpy anchors, spacing holds - flaws invisible small become glaring.
- [ ] Minimum size documented (px for screen, mm for print): just above where identifying features disappear.

## 2. Colour and value
- [ ] One colour black on white; one colour white on black (not heavier - else ship a thinned reversed file).
- [ ] On the brand colour, on photos, on patterns (add a container/outline device if not).
- [ ] Greyscale: segments separate by value; nothing relies on hue alone.
- [ ] Colours have CMYK and spot equivalents if vivid (flag "verify with printer").

## 3. Form
- [ ] Squint/blur: the silhouette alone is distinctive.
- [ ] Mirror: no proportion errors you had adapted to.
- [ ] Rotated 90°/180°, tiny, at distance: no accidental letters, body parts, sexual/offensive/political/religious
      symbols, hazard-sign resemblance. Check readings in the audience's languages (Russian too).
- [ ] Optical corrections: overshoot, bone effect, horizontal thinning, optical centre.
- [ ] Geometry: exact angles, perfect primitives, consistent radii and strokes.
- [ ] Balance: not accidentally tilted; symbol footprint near-square.
- [ ] Letter test: every customised letter reads as itself at first glance.
- [ ] Junctions: no notches, slivers, lumps, hairline gaps or ink traps.
- [ ] Peer test: next to 3-4 excellent marks at the same size it looks equally resolved.

## 4. Distinctiveness
- [ ] Shelf test against competitors: it stands out rather than blending in.
- [ ] Familiarity test: it reminds nobody of an existing mark ("if it feels familiar and isn't yours, it's someone
      else's").
- [ ] Trademark search recommended to the user (cannot give legal clearance).

## 5. Meaning and fit
- [ ] Explained in one sentence; tone matches the adjectives (sharp/round, heavy/light, warm/cool, classic/modern).
- [ ] Identifies rather than explains; still fits if the business expands.
- [ ] Cultural meaning of colours and symbols checked for the audience.
- [ ] Works without the tagline; symbols eventually without the name.

## 6. Media and production
- [ ] One-colour print, embroidery (no hairlines; gaps ≥ ~1mm at chest size), laser engraving, vinyl cutting,
      signage, dark mode, animation.
- [ ] App icon optically sized in the platform's tile; no fine text. Circular avatar crop survives.
- [ ] Master: vector only, text outlined, strokes expanded or flagged, no filters/rasters, clean viewBox.

## 7. Context
- [ ] 4-6 realistic mockups relevant to this business, consistent style. Never judge only on a white artboard.
- [ ] Lockups (horizontal, stacked, symbol-only) tested at their real sizes.

Record results when presenting: what passed, what was adjusted ("opened the counter gap from 6 to 10 units so it
survives 16px; thinned the reversed version 3%"), what the user must still do (trademark search, Pantone proofing).
